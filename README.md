## 프로젝트

### 1. 로컬 AI 실행 환경 구축 및 보안 설정 검증

- 목적: 개인 PC에서 AI를 실행하고 클라우드 기능과 접속 범위를 제한
- 진행일: 2026-10-09
- 환경: Windows, RTX 5080, RAM 32GB, Ollama, Qwen3 14B
- 수행 내용: 모델 실행, GPU 적재 확인, 클라우드 비활성화 확인, 루프백 접속 확인
- 상태: 기본 환경 구축 및 설정 검증 완료

[프로젝트 상세 설명](projects/01-local-ai-setup.md)

### 2. 개인용 보안 로그 분석 도우미

- 목적: 가상 로그인 로그에서 의심 지점을 설명하고 근거와 추가 확인 사항을 제시
- 수행 내용: 가상 로그인 로그를 이용한 수동 질문 실습 시작
- 상태: 실습 진행 중 / 파일 입력과 보고서 자동 생성은 미구현

[프로젝트 상세 설명 및 구현 계획](projects/02-security-log-assistant.md)

### 3. 로컬 문서 검색 도구

- 목적: 지정한 문서에서 관련 내용을 찾아 출처와 함께 답변
- 상태: 계획 단계 / 미구현

[프로젝트 구현 계획](projects/03-document-search.md)

## 기록 원칙

- 실행 결과로 확인한 내용과 앞으로 구현할 내용을 구분합니다.
- 실제 개인정보, 비밀번호, API 키, 회사 문서는 공개하지 않습니다.
- AI 답변은 검증 대상이며 취약점이나 공격 여부의 확정 근거로 취급하지 않습니다.
- AI의 도움을 받아 구축·문서화하며, 명령과 결과의 의미를 학습하고 기록합니다.

# 로컬 문서 검색 도구

[포트폴리오 목록으로 돌아가기](../README.md)

## 목적과 현재 상태

개인 학습 문서에서 질문과 관련된 부분을 검색하고 파일명과 위치를 함께 제시하는 도구를 만든다.
현재는 계획 단계이며 문서 수집, 검색, 답변 생성 기능은 미구현이다.

## 초기 범위

- 본인이 작성한 공개 가능한 Markdown 또는 텍스트 문서
- 지정한 폴더 안의 문서만 읽기
- 관련 문단 검색 후 Qwen3에 제공
- 답변에 원문 위치 표시
- 근거가 없으면 문서에서 확인할 수 없다고 답변

PDF 지원은 텍스트 추출과 페이지 위치 확인이 필요하므로 기본 텍스트 검색 이후에 추가한다.

## 구현할 흐름

문서 → 문단 분리 → 로컬 임베딩 모델로 검색 색인 생성 → 질문에 관련된 문단 검색 → Qwen3 답변 → 출처 표시

검색용 임베딩 모델은 대화 모델과 별도로 선택하고 다운로드해야 한다.

## 평가 계획

- 문서 안에 정답이 있는 질문: 관련 문단과 출처가 맞는지 확인
- 문서에 답이 없는 질문: 근거 없이 답을 만들어내는지 확인
- 서로 다른 문서의 내용이 충돌하는 질문: 출처별 차이를 설명하는지 확인
- 문서에 삽입된 지시 문구: 문서 데이터를 프로그램 지시로 따르는지 확인
